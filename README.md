# EAVT — локальный тренажёр тестов

Локальное приложение для прохождения экзаменационных тестов EAVT. Работает без сервера и без интернета (после установки картинок).

## Запуск

Откройте **`index.html`** в браузере — всё.

Или через локальный сервер (для надёжности):
```
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Что внутри

- `index.html` — само приложение (SPA, без зависимостей): вёрстка + весь CSS,
  включая Aurora-фон, дорожную карту и стеклянные панели
- `app.js` — логика: роутер, i18n, экзамен, марафон, SRS, статистика
- `data.js` — 63 шаблона, 1255 вопросов с ответами и пояснениями (~1.4 МБ)
- `images/img/...` — картинки вопросов (870 шт., если распакованы)
- `eavt_63_final.json` — исходный дамп
- `build_data.py` — регенерация `data.js` из дампа
- `fetch_images.js` — скрипт для консоли браузера: скачивает картинки с сервера в `images.json`
- `unpack_images.py` — распаковка `images.json` в `images/img/`

## Режим картинок

Приложение сначала ищет картинку локально в `images/img/...`. Если файла нет — подгружает с `https://back.eavtotalim.uz`.

**Сделать полностью офлайн:**

1. Откройте https://eavtotalim.uz в браузере, залогиньтесь
2. Откройте DevTools → Console, вставьте содержимое `fetch_images.js`, запустите
3. Дождитесь скачивания `images.json` (~5–15 мин)
4. В папке приложения выполните: `python3 unpack_images.py images.json`
5. Готово — приложение больше не требует интернета

## Возможности

- Список 63 шаблонов с лучшим результатом по каждому
- Экзамен: 20 вопросов, таймер 25 минут
- Картинки в вопросах и ответах
- Марафон с паузой: кнопка «Пауза и сохранить» останавливает таймер и сохраняет
  сессию, продолжить можно позже с того же вопроса (прогресс не теряется и при
  случайном закрытии вкладки)
- Автопереход к следующему вопросу после ответа
- Мгновенный результат с процентом и зачётом (≥70%)
- Полный разбор: правильный/выбранный ответ, пояснение
- Прогресс хранится в localStorage браузера
- Кнопка сброса прогресса
